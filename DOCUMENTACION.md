# 🏦 Sistema de Cobranza (Canary 1.2)

Sistema integral de gestión financiera diseñado para administrar préstamos, controlar cobros de rutas diarias y supervisar operaciones de campo. 
Resuelve la digitalización del proceso de cobranza y mitiga fraudes mediante geolocalización y control de dispositivos.

## Resumen para IA
**Cobranza-canary1.2** es una plataforma SaaS/Monolítica (Next.js, Prisma, PostgreSQL). El core es la gestión de préstamos, intereses y cuotas en campo. Maneja control de caja chica, pago de comisiones y autorización de dispositivos móviles para los cobradores. El sistema se enlaza a herramientas externas (n8n, Meta API) para integrarse con Robotina y gestionar notificaciones de WhatsApp.
