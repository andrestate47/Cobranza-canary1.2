# Stack Tecnológico

El proyecto utiliza tecnologías modernas para garantizar escalabilidad y rendimiento, siguiendo las directrices de la [[Arquitectura del Sistema]].

- **Frontend**: React 18, Next.js 14, Tailwind CSS, Radix UI, Framer Motion.
- **Backend**: Node.js (via Next.js API Routes).
- **Base de Datos**: PostgreSQL y Prisma ORM (v6.7).
- **Autenticación**: NextAuth.js (JWT) (ver [[Seguridad y Autenticación]]).
- **Almacenamiento**: AWS S3 (para comprobantes y fotos).
- **Mapas/Geolocalización**: Leaflet, Mapbox.
- **Gráficos y utilidades**: Chart.js, Recharts, Plotly, HTML2Canvas, Zustand/Jotai.
